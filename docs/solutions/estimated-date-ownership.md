# 자동 예상 날짜와 사용자 지정 날짜의 소유권

## Problem

예상 날짜를 기본값으로 보여주면서 사용자가 편집하게 하면, 조건 변경이나 늦은 요청 응답이 사용자가 선택한 날짜를 덮어쓸 수 있다.

## Cause

서버가 계산한 값과 사용자의 의도를 날짜 값 하나로만 표현하면 같은 날짜라도 자동/직접 지정 여부를 구별할 수 없다.

## Solution

자동 미리보기는 조건별 Query key로 관리하고 직접 지정 날짜는 React Hook Form에 둔다. automatic/manual/none 모드를 구별하며 저장 응답은 calculated/user 출처를 가진다. 자유 입력 이름 대신 standardIngredientId로 계산한다.

## Prevention

가입부터 수동 날짜 지정, 보관 위치 변경, 저장된 날짜/출처 확인까지 통합 테스트에 포함했다. 인증 전환은 세션 세대 번호로 오래된 등록 응답의 후속 동작을 무시한다.

## Generalizable Rule

자동 추천값을 편집할 수 있는 입력에서는 값뿐 아니라 사용자가 직접 정했는지를 모델링한다. 새로운 자동 응답은 명시적 사용자 입력을 덮어쓰지 않는다.
